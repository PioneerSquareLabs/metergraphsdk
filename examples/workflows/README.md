# Customer workflows

These examples begin with a customer-facing workflow and show how its calls
map to MeterGraph traces and routes. Use them when you want the dashboard to
match how a product is experienced.

Each workflow README identifies:

- the logical `trace()` around the user-visible operation;
- the `route()` scopes that should appear as separate workloads; and
- the provider or framework implementation used by the example.
